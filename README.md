# Secure Messaging Prototype (AES & ChaCha20)

This repository contains a Python-based secure messaging prototype developed
as part of a Final Year Project.

## Description
The prototype demonstrates symmetric encryption and decryption using
AES and ChaCha20. It allows a user to input a message, encrypt it,
decrypt it, and record encryption and decryption times.

## Requirements
- Python 3.x
- PyCryptodome

## Installation
pip install pycryptodome
